# NeuroLit AI User Guide

This short guide is for everyday users of NeuroLit AI.

## 1. Install the App

1. Download `NeuroLit_Setup.exe` from the GitHub Release page.
2. Run the installer.
3. Use the Desktop shortcut or Start Menu entry to open the app.

## 2. Open Settings First

In `Settings`, check:

- your AI provider profile
- your NeuroLit data folder
- your update settings

## 3. Choose the Correct Mode

NeuroLit AI has two modes:

- `Medical`
- `Engineering`

These modes keep their saved outputs separate.

## 4. Search and Select Articles

1. Enter a search query
2. Review the results
3. Tick the articles you want

## 5. Generate Outputs

Use:

- `Professional Output` for research-style AI summaries
- `Layman Output` for simpler explanations

## 6. Save and Reopen Work

Collections, summaries, exports, and other files are stored in your NeuroLit data folder.

If you cannot find a file:

1. Open `Settings`
2. Check `NeuroLit Data Folder`
3. Click `Open Folder`

## 7. If Your Documents Folder Is in OneDrive

That is okay, but you may prefer a custom NeuroLit folder.

Use:

- `Choose Folder`

to select a dedicated location such as:

`C:\NeuroLitData`

## 8. Updating the App

When a new version is available:

1. Download the new installer from GitHub Releases
2. Close the app
3. Run the installer

You can also use the `Check for Updates` button in `Settings`.
